## Feedback

An empty line in a doc comment becomes a line of spaces in the help output.

The doc of a command, argument, or option may span several lines. In the
full `--help`, every line of that doc is written with the offset prepended
(`format!("{:offset$}{line}{newline}", "", offset = offset)` in
`build_commands`, `build_arguments`, and `build_options`). A blank line in
the doc is therefore written as offset many spaces followed by a newline,
and the help output carries trailing whitespace on those lines.

For example, this program's own help for a command whose doc reads

    Say in each command's full help which explain topic to read.

    The topic is given by name, as `nokori explain kinds` lists them.

prints the second line (the blank one) as four spaces.

The trailing whitespace is invisible as output, but it shows up in diffs,
and tools that strip trailing whitespace rewrite the help of every program
that relies on it. Whether an offset belongs on a blank line at all is a
question for this repository: a blank line is not indented text, and the
three places that do it are the same shape, so a fix would be a decision
made once.
